## 小程序演示建议

1. 用 `chenze-itinerary.json` 里的 `mapMarkers` 在地图页批量打点（或手动按时间线补录）。
2. **时间线页**：按 `timeline[].sortKey` 排序展示。
3. **统计页**：2026 共 **7** 个不同城市、**3** 国/地区；重庆 **2** 次可单独强调。
4. 笔记配图：地图全览截图 + 9 月密集行程日历截图 + 单城卡片（重庆/东京各一张）。

## 结构化数据

完整字段（含经纬度、标签、同行人）见同目录 **`chenze-itinerary.json`**。

### 一键导入小程序数据库

```bash
docker compose up -d mysql   # 若本地 MySQL 未启动
cd api
cp .env.example .env       # 首次
npm run seed:chenze          # 会自动 prisma db push 建表，再导入 11 条
```

会创建/更新演示用户 `demo_chenze_footprint`（昵称「陈泽·足迹演示」），写入 11 条打卡。默认会先删掉带 `#chenze-import:` 标记的旧演示数据再导入；追加模式：`npx tsx scripts/import-chenze-itinerary.ts --append`。

小程序开发工具里用 **dev-login**，body 传固定 `openid: "demo_chenze_footprint"` 即可看到同一份地图与时间线（需 API 的 `DEV_MODE=true`）。
